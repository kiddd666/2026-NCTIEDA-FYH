# 01. 数字设计基础

## 1. 信号：0、1、X、Z

| 状态  | 通俗解释        | 常见原因          | 对测试的影响          |
| --- | ----------- | ------------- | --------------- |
| `0` | 明确的低电平      | 被某个驱动器拉低      | 可以被控制和观察        |
| `1` | 明确的高电平      | 被某个驱动器拉高      | 可以被控制和观察        |
| `X` | 不知道是 0 还是 1 | 未初始化、冲突、时序不确定 | 可能污染后级逻辑，掩盖故障   |
| `Z` | 高阻          | 三态驱动器关闭、总线悬空  | 需要确认是否有唯一驱动或保持器 |

`X` 不是“第三种正常电平”，而是仿真器在提醒你“当前信息不足”；`Z` 也不是自动等于 `0`。因此读网表时，**看到三态缓冲器或未连接端口，要继续追踪它在测试模式下是否有确定值**。[数字设计教材第 2 章与 HDL 章节](<../../学习材料/DFT补强/数字设计和计算机体系结构原书第2版.md>)

## 2. 组合逻辑

组合逻辑没有记忆。与门、或门、非门、加法器和比较器都属于这一类。**MUX（多路复用器）** 是 DFT 中最常见的组合结构之一：它用选择信号 `S` 在两个输入之间“二选一”。一个 2:1 MUX 可以写成：

```text
Y = S ? B : A
```

当 `S=0`，`Y=A`；当 `S=1`，`Y=B`。扫描单元（Scan Cell）正是利用这个“二选一”能力，在正常数据 `DI` 和扫描数据 `SI` 之间切换。三态缓冲器则多了一个“是否接入总线”的使能端（Scan_en）：关闭时输出为 `Z`，开启时才驱动 `0/1`。

>同一条总线如果有两个驱动器同时开启并输出相反值，就会发生冲突；这也是 Scan DRC 特别关注三态结构的原因。[英文 DFT 教材第 2.6.1～2.6.2 节](<../../学习材料/DFT补强/VLSI Test Principles and Architectures - Design for Testability.md>)

## 3. 时序单元：把值“保存到下一次时刻”

### 3.1 DFF 与 DLATCH

- **D 触发器（DFF）**在时钟的某个边沿采样 `D`，随后把采样值保持在 `Q`，直到下一次有效边沿。
- **D 锁存器（DLATCH）**在时钟或使能处于有效电平的整个窗口内都可能跟随 `D`；窗口关闭后才保持。

可以用“拍照”来类比：DFF 只在快门按下的一瞬间拍照，DLATCH 则在快门打开的整段时间里都能更新。两者都可能带有：

- **使能（enable）**：允许更新，否则保持原值；
- **同步复位/置位**：等到时钟边沿才生效；
- **异步复位/置位**：不等时钟，控制信号一变化就可能立即改变 `Q`。

> **异步控制**让功能设计更快地进入安全状态，却会让扫描时的移位受到干扰；因此后续 DRC 会要求它们在测试期间可控或保持无效。[数字设计教材第 3.2、4.4 节](<../../学习材料/DFT补强/数字设计和计算机体系结构原书第2版.md>)；[英文 DFT 教材第 2.6.6 节](<../../学习材料/DFT补强/VLSI Test Principles and Architectures - Design for Testability.md>)

### 3.2 上升沿、下降沿与“什么时候算新值”

有些单元在时钟**上升沿**（`0→1`）采样，有些在**下降沿**（`1→0`）采样。读门级实例时，应把时钟引脚的角色记下来。混合正、负边沿单元串成扫描链时，边沿顺序会直接影响保持时间风险，见[第 04 篇](<04_时钟边沿与Lockup.md.md>)。

## 4. 建立时间、保持时间和时钟偏移

把一个触发器看成“接收站”：

- **建立时间（setup）**：时钟到来前，`D` 必须提前稳定一小段时间；
- **保持时间（hold）**：时钟到来后，`D` 还要继续稳定一小段时间；
- **时钟偏移（skew）**：同一时钟到达不同单元的时间不完全相同。

功能路径通常担心“数据来晚了”导致 setup 失败；扫描移位常见的是“前一个单元刚推出的数据来得太快”，叠加时钟偏移后让后一个单元的 hold 失败。**Lockup latch/flip-flop** 就是为这类扫描路径增加安全时间窗口的结构。[数字设计教材第 3.5 节](<../../学习材料/DFT补强/数字设计和计算机体系结构原书第2版.md>)；[英文 DFT 教材第 2.7.4.1 节](<../../学习材料/DFT补强/VLSI Test Principles and Architectures - Design for Testability.md>)

## 5. 门级网表

门级网表是对元件和连线的结构描述（verilog有行为级建模与结构化建模，门级网表属于结构化建模）。建议按以下顺序读：

1. 先找到顶层 `module`，列出输入、输出和内部 `wire`；
2. 找实例化语句，确认每个单元的类型及端口连接；
3. 找连续赋值 `assign`，看组合逻辑如何把一根线驱动到另一根线；
4. 追踪 `D/Q/CK`（或等价引脚）识别触发器和锁存器；
5. 单独标出复位、置位、使能、门控时钟和三态使能。

```verilog
// 行为级描述
always @(posedge clk or negedge rst_n) begin
    if (!rst_n)
        q <= 1'b0;
    else if (scan_en)
        q <= scan_in;
    else
        q <= functional_d;
end

//带 Scan MUX 的扫描触发器结构级描述
wire next_d;
assign next_d = scan_en ? scan_in : functional_d;
DFF_X1 u_ff (
	.D(next_d), 
	.CK(clk), 
	.Q(q), 
	.RN(rst_n)
);
```

`scan_en ? ...` 是一个 MUX。`u_ff` 是一个由 `clk` 触发、由低有效异步复位 `rst_n` 控制的存储单元。完整语法由 IEEE 1800 标准定义，教材第 4 章提供了足够的结构化读法。[IEEE 1800 标准入口](https://standards.ieee.org/ieee/1800/)

## 6. 从移位寄存器到最基本的扫描链

把多个 DFF 的 `Q` 接到下一个 DFF 的 `D`，就得到移位寄存器。扫描链只是在每个存储单元前增加一个 MUX：

```text

Scan DFF：
                  scan_en
                     |
  功能数据(D) ───┐    v
                ├── MUX ──> DFF ──> Q ──► 下一个单元 SI
   SI   ────────┘


```

- `scan_en=1`：选择 `SI`，每个时钟把数据向后移一格（Shift）；
- `scan_en=0`：选择功能数据，时钟到来时把组合逻辑结果装入单元（Capture）；
- 最后一个单元的 `Q` 接到 `scan_out`，最前一个单元接 `scan_in`。

这样，原来难以直接设置和读取的内部状态，就能通过少数几个测试端口逐位移入、移出。这个直觉是理解后面 Internal Scan、链平衡和 DRC 的起点。[英文 DFT 教材第 2.4～2.5 节](<../../学习材料/DFT补强/VLSI Test Principles and Architectures - Design for Testability.md>)；[数字设计教材第 5.4 节“扫描链”](<../../学习材料/DFT补强/数字设计和计算机体系结构原书第2版.md>)
