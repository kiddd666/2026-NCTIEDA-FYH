# 第二章

本章讨论用于测试现代数字电路的可测性设计（design for testability, DFT）技术。这些 DFT 技术用于提高数字电路的质量并降低其测试成本，同时简化测试、调试与诊断任务。本章的目的是让读者具备相应的知识，能够判断一项设计是否以利于测试的方式实现，并能提出改进建议以提升设计的可测性（testability），从而实现上述目标。更具体地说，本章将使读者能够**识别并修复扫描设计规则违例，并理解将一项设计成功转换为扫描设计（scan design）的基础知识。**

在本章中，我们首先介绍执行可测性分析（testability analysis）的基本 DFT 概念与方法。接着，在简要而全面地概述专用（ad hoc）DFT 技术之后，将讨论应用最广泛的结构化 DFT 方法——**扫描设计**，内容包括常用的扫描单元（scan cell）设计、扫描架构、扫描设计规则、扫描设计流程以及特殊用途的扫描设计。最后，介绍可在寄存器传输级（register-transfer level, RTL）使用的先进 DFT 技术，以进一步减少 DFT 设计迭代和测试开发时间。

# 2.1

在集成电路（integrated circuit, IC）生产历史的早期，设计与测试被视为彼此分离的职能，由互不相干的两组工程师分别完成。在那个年代，设计工程师的职责是根据设计规格实现所需功能，完全不考虑制造出来的器件将如何被测试。功能实现之后，设计信息才被移交给测试工程师。测试工程师的职责是确定如何在合理的时间内高效地测试每一颗制造出来的器件，以筛选出可能含有制造缺陷的零件，并将所有无缺陷的器件交付客户。测试的最终质量依据客户退货情况，通过统计交付到客户手中的缺陷零件数量来衡量。这种以每百万缺陷零件数（defective parts per million, PPM）计量的产品质量，就是量化所开发测试有效性的最终测试评分。

这种方法对于主要由组合逻辑或简单有限状态机构成的小规模集成电路行之有效，但随着设计从小规模集成（small-scale integration, SSI）发展到超大规模集成（very-large-scale integration, VLSI），它已无法跟上电路复杂度的增长。20 世纪 80 年代测试这些 VLSI 器件的常见做法，是高度依赖故障仿真（fault simulation）来衡量所提供功能向量的故障覆盖率（fault coverage）。功能向量的开发要遍历设计深长的时序深度（sequential depth），目标是激励所有内部状态并检测所有可能的制造缺陷。故障仿真或故障评分（fault grading）工具被用来量化功能向量的有效性。如果所提供的功能向量未能达到目标故障覆盖率，就继续追加功能向量。遗憾的是，这种方法通常无法把电路的故障覆盖率提升到  以上，出厂产品的质量也因此受损。

人们逐渐认识到，在设计器件时对测试关注不足，会导致测试成本上升、测试质量下降。一些在功能和性能方面本属一流的设计，却因测试成本高得难以承受或产品质量不佳而在商业上失败。这些问题此后促使业界发展并部署了 DFT 工程。

DFT 工程师面临的首要挑战，是找到更简单的方法来激励设计的所有内部状态并达到目标故障覆盖率。为此，20 世纪 70 年代和 80 年代提出并使用了各种可测性度量方法与专用（ad hoc）可测性增强方法。这些方法主要用于改善电路的可测性，或提高电路的**可控性（controllability）与可观测性（observability）**。虽然使用这些方法的尝试显著改善了设计的可测性，并降低了**时序自动测试向量生成**（**automatic test pattern generation, ATPG**）的难度，但其最终在达到目标故障覆盖率方面的效果远不能令人满意；对大型设计而言，故障覆盖率要超过 90% 仍然相当困难。这主要是因为，即使借助这些可测性辅助手段，人工推导功能向量或为时序电路生成测试向量，仍是远难于为组合电路生成测试向量的问题。

对于组合电路，业界已开发出许多新颖的 ATPG 算法，能够在合理的时间内自动生成测试向量。而为时序电路自动生成测试向量只取得了有限的成功，原因在于时序电路存在大量难以从外部引脚设置和检查的内部状态。由于难以控制和观测时序电路的内部状态，**结构化 DFT 方法**应运而生：**为存储元件（storage element）提供直接的外部访问**。**这类经过改造、具有直接外部访问能力的存储元件，通常被称为扫描单元（scan cell）**。一旦具备了控制和观测设计内部状态的能力，时序电路的测试问题就转化为组合逻辑的测试问题，而后者早已存在许多成熟的解决方法。

扫描设计是目前最流行的结构化 DFT 方法。它通过把设计中选定的存储元件连接成多个移位寄存器（称为扫描链（scan chain）），来为这些存储元件提供外部访问。==扫描设计的实现方式是：将所有选定的存储元件替换为扫描单元，每个扫描单元增加一个扫描输入（scan input, SI）端口和一个共享/附加的扫描输出（scan output, SO）端口。把一个扫描单元的 SO 端口连接到下一个扫描单元的 SI 端口，即可构成一条或多条扫描链。==

自 20 世纪 70 年代以来，人们已提出大量扫描单元设计和扫描架构。所有存储元件都被选中进行扫描插入（scan insertion）的设计称为**全扫描设计**（full-scan design）。几乎所有（例如超过 ）存储元件都被选中的设计称为**准全扫描设计**（almost full-scan design）。只选中部分存储元件并采用时序 ATPG 的设计称为**部分扫描设计**（partial-scan design）。如果部分扫描设计在选取存储元件时切断了所有时序反馈回路，从而可以应用组合 ATPG，则进一步细分为流水线式、前馈式或平衡式部分扫描设计。随着 20 世纪 90 年代中期深亚微米技术的出现、硅片价格持续下降，主流扫描架构已从部分扫描设计转向全扫描设计。

为了使扫描设计达到预期的 PPM 目标，必须识别并修复可能影响故障覆盖率的特定电路结构和设计做法。这就需要制定一套必须遵守的扫描设计规则。由此催生了一个新角色——DFT 工程师，其职责包括：识别并修复设计中的扫描设计规则违例，在设计中插入或综合出扫描链，为扫描设计生成测试向量，最后把测试向量转换为测试程序，供测试工程师在自动测试设备（automatic test equipment, ATE）上执行制造测试。此后，上述 DFT 任务中的大部分都已实现自动化。

扫描设计除了是用于检测制造缺陷的主导性 DFT 架构之外，还已成为更先进 DFT 技术的基础，**例如逻辑内建自测试**（logic built-in self-test, BIST）和**测试压缩（test compression）**。此外，随着设计不断迈向纳米尺度，扫描设计正被用作一种设计特性，用途涵盖调试、诊断和失效分析，以及诸如针对软错误的可靠性增强等特殊应用。为求完整，本章收录了其中若干特殊用途的扫描设计。

近年来，可测性设计已开始从门级迁移到**寄存器传输级（RTL）**。这一迁移的动机，是让逻辑 BIST 和测试压缩等附加 DFT 特性能在 RTL 集成，从而缩短测试开发时间，并创建可复用且可测试的 RTL 核。这还进一步使集成后的 DFT 设计能够经过基于综合的优化，以降低性能与面积开销。

## 2.2 可测性分析（testability analysis）

可测性（testability）是测试一个逻辑电路所需工作量或成本的相对度量。一般而言，它基于这样的假设：**只有主输入（primary inputs）和主输出（primary outputs）能分别被直接控制和直接观测**。可测性反映了执行主要测试操作所需的工作量，即从主输入控制内部信号以及在主输出观测内部信号。可测性分析（testability analysis）是指通过为电路中每个信号计算一组数值度量来评估逻辑电路可测性的过程。

可测性分析的一个重要应用是辅助测试生成过程中的决策。例如，若在测试生成过程中确定某个与门（AND gate）的输出必须置为 0，可测性分析可以帮助判断该与门的哪个输入最容易被置为 0。另一个应用是识别可测性较差的区域，以指导可测性增强（如测试点插入（test point insertion）），从而改善设计的可测性。为此，需要在各个设计阶段执行可测性分析，以便尽早发现并修复可测性问题。

自 20 世纪 70 年代以来，已有许多可测性分析技术被提出。Sandia 可控性/可观测性分析程序（Sandia Controllability/Observability Analysis Program，SCOAP）是首个基于拓扑结构的程序，它推广了可测性分析的应用。人们还开发了许多基于 SCOAP 的改进方法，用于辅助测试点选择。这些方法通过计算每条信号线的可控性（controllability）和可观测性（observability）来进行可测性分析，其中**可控性反映从主输入将信号线设置为所需逻辑值的难度**，**可观测性反映将信号线的逻辑值传播到主输出的难度**。

传统上，可测性分析使用电路的门级拓扑信息，并根据目标应用计算确定性或随机的可测性测度（measure）。总体而言，**基于拓扑的可测性分析**（如 SCOAP 或基于概率的（probability-based）可测性分析）计算效率高，但对包含大量再汇聚扇出（reconvergent fanout）的电路可能给出不准确的结果。另一方面，**基于仿真的（simulation-based）可测性分析**通过使用确定性、随机或伪随机测试向量（test pattern）对电路行为进行仿真，能够产生更准确的结果，但可能需要很长的仿真时间。

本节首先介绍执行 SCOAP 可测性分析的方法，接着讨论基于概率的可测性分析和基于仿真的可测性分析，最后讨论如何进行 RTL 可测性分析——因为在 RTL 上执行可测性分析的能力正变得日益重要。

### 2.2.1 SCOAP

SCOAP 可测性分析程序为逻辑电路中的每个信号 s 计算六个数值：

■ CC0(s)—s 的组合 0 可控性（combinational 0-controllability） 
■ CC1(s)—s 的组合 1 可控性
■ CO(s)—s 的组合可观测性
■ SC0(s)—s 的时序 0 可控性（sequential 0-controllability）
■ SC1(s)—s 的时序 1 可控性
■ SO(s)—s 的时序可观测性

粗略地说，三个组合可测性测度（CC0、CC1 和 CO）与为从主输入控制 s 或在主输出观测 s 所需操纵的**信号数量**相关；而三个时序可测性测度（SC0、SC1 和 SO）与为从主输入控制 s 或在主输出观测 s 所需的**时钟周期数**相关。可控性测度的取值范围是 1 到无穷大，可观测性测度的取值范围是 0 到无穷大。作为**边界条件**，主输入的 CC0 和 CC1 值设为 1，主输入的 SC0 和 SC1 值设为 0，主输出的 CO 和 SO 值设为 0。

#### 2.2.1.1 组合信号可控性与可观测性计算

SCOAP 的第一步是计算所有信号的组合可控性测度。该计算按广度优先方式从主输入向主输出进行。更具体地说，先对电路从主输入到主输出进行分级（levelize），为每个门赋予一个层级序号；然后按层级顺序，在某个门全部输入的可控性测度都计算完毕之后，再计算该门输出的可控性。组合可控性的计算规则汇总于表 2.1，每条规则都加 1，表示信号多经过了一级逻辑门。由该表可见，对任何信号 s 都有 CC0(s)≥1 且 CC1(s)≥1。CC0(s) 或 CC1(s) 的值越大，表示从主输入将 s 控制为 0 或 1 越困难。

一旦计算出所有信号的组合可控性测度，就可以计算每个信号的组合可观测性。该计算同样按广度优先方式进行，只是方向为从主输出向主输入。组合可观测性的计算规则汇总于表 2.2，每条规则都加 1，表示信号多经过了一级逻辑门。由该表可见，对任何信号 s 都有 $\mathrm{CO}(s) \geq 0$。$\mathrm{CO}(s)$ 的值越大，表示在任何主输出处观测 s 越困难。

#### 2.2.1.2 时序可控性和可观测性计算

时序可控性与可观测性测度的计算方式与组合测度类似，不同之处在于：**从一个逻辑门级别移到另一个级别时不加 1，而是在信号经过一个存储元件（storage element）时才加 1**。图 2.2 所示的时序电路示例说明了这一差别，该电路由一个与门和一个正边沿触发的 D 触发器组成，该 D 触发器包含一个高电平有效的异步复位引脚 r。

首先，我们计算所有信号的组合可控性与时序可控性测度。要将信号 d 控制为 0，输入 a 或 b 中至少有一个必须置为 0；要将 d 控制为 1，输入 a 和 b 必须都置为 1。因此，信号 d 的组合可控性与时序可控性测度为：

要将 D 触发器的数据输出 q 控制为 0，可以将数据输入 d 和复位信号 r 置为 0，同时向时钟 CK 施加一个上升时钟沿（0 到 1 的跳变）；另一种做法是将 r 置为 1 并保持 CK 为 0。由于第二种情况未向 CK 施加时钟脉冲，时序可控性计算中不加 1；因此，q 的组合 0 可控性与时序 0 可控性测度为：

$$
\begin{array}{l} \mathsf {C C 0} (q) = m i n \{\mathsf {C C 0} (d) + \mathsf {C C 0} (C K) + \mathsf {C C 1} (C K) + \mathsf {C C 0} (r), \mathsf {C C 1} (r) + \mathsf {C C 0} (C K) \} \\ \mathsf {S C 0} (q) = m i n \{\mathsf {S C 0} (d) + \mathsf {S C 0} (C K) + \mathsf {S C 1} (C K) + \mathsf {S C 0} (r) + 1, \mathsf {S C 1} (r) + \mathsf {S C 0} (C K) \} \end{array}
$$
其中，$CC0(q)$ 衡量电路中必须设置多少个信号才能将 q 控制为 0，而 $SC0(q)$ 衡量电路中必须给多少个触发器送时钟才能将 q 置为 0。将 D 触发器的数据输出 q 控制为 1 的唯一方法是：将数据输入 d 置为 1、复位信号 r 置为 0，并向时钟 CK 施加上升时钟沿。因此，

$$
\begin{array}{l} \mathsf {C C 1} (q) = \mathsf {C C 1} (d) + \mathsf {C C 0} (C K) + \mathsf {C C 1} (C K) + \mathsf {C C 0} (r) \\ \mathsf {S C 1} (q) = \mathsf {S C 1} (d) + \mathsf {S C 0} (C K) + \mathsf {S C 1} (C K) + \mathsf {S C 0} (r) + 1 \end{array}
$$
接下来，我们计算所有信号的组合可观测性与时序可观测性测度。将复位信号 r 保持为 0 并向 CK 施加上升时钟沿，即可在 q 处观测数据输入 d。因此，

$$
\begin{array}{l} \mathbf {C O} (d) = \mathbf {C O} (q) + \mathbf {C C 0} (C K) + \mathbf {C C 1} (C K) + \mathbf {C C 0} (r) \\ \mathbf {S O} (d) = \mathbf {S O} (q) + \mathbf {S C 0} (C K) + \mathbf {S C 1} (C K) + \mathbf {S C 0} (r) + 1 \end{array}
$$
要观测异步复位信号 r，可以先将 q 置为 1，再将 CK 保持在无效状态 0。同样，由于未向 CK 施加时钟脉冲，时序计算中不加 1：

$$
\begin{array}{l} \mathrm{CO} (r) = \mathrm{CO} (q) + \mathrm{CC1} (q) + \mathrm{CC0} (C K) \\ \mathrm{SO} (r) = \mathrm{SO} (q) + \mathrm{SC1} (q) + \mathrm{SC0} (C K) \end{array}
$$
有两种方法可在 q 处间接观测时钟信号 CK：(1) 将 q 置 1、r 置 0、d 置 0，并在 CK 上施加上升时钟沿；或 (2) 将 q 和 r 都置 0、d 置 1，并在 CK 上施加上升时钟沿。因此，

$$
\begin{array}{r l} \mathbf {C O} (C K) & = \mathbf {C O} (q) + \mathbf {C C 0} (C K) + \mathbf {C C 1} (C K) + \mathbf {C C 0} (r) \\ & \quad + m i n \{\mathbf {C C 0} (d) + \mathbf {C C 1} (q), \mathbf {C C 1} (d) + \mathbf {C C 0} (q) \} \\ \mathbf {S O} (C K) & = \mathbf {S O} (q) + \mathbf {S C 0} (C K) + \mathbf {S C 1} (C K) + \mathbf {S C 0} (r) \\ & \quad + m i n \{\mathbf {S C 0} (d) + \mathbf {S C 1} (q), \mathbf {S C 1} (d) + \mathbf {S C 0} (q) \} + 1 \end{array}
$$
要在 d 处观测与门的一个输入，需要将另一个输入置为 1；因此，输入 a 和 b 的组合可观测性与时序可观测性测度分别为：

$$
\begin{array}{l} \mathrm{CO} (a) = \mathrm{CO} (d) + \mathrm{CC1} (b) + 1 \\ \mathrm{SO} (a) = \mathrm{SO} (d) + \mathrm{SC1} (b) \\ \mathrm{CO} (b) = \mathrm{CO} (d) + \mathrm{CC1} (a) + 1 \\ \mathrm{SO} (b) = \mathrm{SO} (d) + \mathrm{SC1} (a) \end{array}
$$
需要注意的是，用 SCOAP 计算出的可控性和可观测性测度是一种启发式估计，只是对逻辑电路实际可测性的近似。当采用扫描设计（scan design）时，可测性分析可以假设所有扫描单元（scan cell）都是可直接控制和可直接观测的。对于包含大量再汇聚扇出的电路，SCOAP 可能高估其可测性测度；不过，SCOAP 能以 $O(n)$ 的计算复杂度对电路中的 $n$ 个信号完成可测性分析，从而快速估计电路的可测性，用于指导可测性增强和测试生成。

### 2.2.2 基于概率的可测性分析技术

实践表明，SCOAP 等基于拓扑的可测性分析技术对测试生成（第 4 章的主题）极为有用，这类可测性测度能够提前分析逻辑电路的确定性可测性。另一方面，在逻辑内建自测试（logic built-in self-test，BIST，第 5 章的主题）中，随机或伪随机测试向量的生成不需要对任何信号线专门执行确定性测试生成。此时可以采用基于拓扑、利用信号概率来分析电路随机可测性的可测性测度。这类测度通常称为基于概率的可测性测度或基于概率的可测性分析技术。例如，给定一个随机输入向量，可以为组合电路中的每个信号 s 计算如下三个测度：

■ C0(s)—s 的基于概率的 0 可控性
■ C1(s)—s 的基于概率的 1 可控性
■ O(s)—s 的基于概率的可观测性

其中，$C0(s)$ 和 $C1(s)$ 分别是从主输入将信号 s 控制为 0 和 1 的概率，$O(s)$ 是在主输出处观测信号 s 的概率。这三个概率的取值范围都在 0 和 1 之间。作为边界条件，主输入的 C0 和 C1 概率通常设为 0.5，主输出的 O 概率设为 1。对电路中的每个信号 s，有 $C0(s) + C1(s) = 1$。

人们已开发出许多计算基于概率的可测性测度的方法。下面给出一种简单方法，其基本流程与 SCOAP 中计算组合可测性测度的流程类似，只是采用不同的计算规则。基于概率的可控性和可观测性计算规则分别汇总于表 2.3 和表 2.4。在表 2.3 中，$p_{0}$ 是为主输入选定的初始 0 可控性，其中 $0 < p_{0} < 1$。

这类抗随机向量故障的存在，是随机或伪随机测试向量的故障覆盖率低于确定性测试向量的主要原因。在逻辑 BIST 等应用中，为解决故障覆盖率低的问题，通常在电路中插入测试点以增强电路的随机可测性。几种常用的测试点插入技术将在 2.3 节讨论，有兴趣的读者可以在第 5 章找到更多信息。

### 2.2.3 基于仿真的可测性分析

如上所述，在计算 SCOAP 和基于概率的可测性测度时，只显式利用了逻辑电路的拓扑信息。这些基于拓扑的方法是静态的，即不使用输入测试向量进行可测性分析。其可控性和可观测性测度可以在线性时间内算出，因此对需要快速可测性分析的应用（如测试生成和逻辑 BIST）非常有吸引力。然而，这些方法的高效率是以精度下降为代价的，对包含大量再汇聚扇出的电路尤其如此。

作为静态（基于拓扑）可测性分析的替代或补充，可以通过统计采样执行动态（基于仿真）的方法，即利用输入测试向量进行可测性分析或可测性增强。为此可以采用逻辑仿真和故障仿真技术，两者都将在第 3 章介绍。

在统计采样中，先选取一组输入测试向量样本（可随机生成，也可取自给定的向量集），然后进行逻辑仿真，收集全部或部分所关注信号线的响应。常用的响应数据是 0、1、0 到 1 跳变和 1 到 0 跳变的出现次数，用于对逻辑电路的可测性进行统计刻画；再对这些数据进行分析，找出可测性差的位置。如果某条信号线在样本输入向量下只出现很少的跳变或没有跳变，则可能表明该信号的可控性较差。

除逻辑仿真外，故障仿真也被用于改善电路在使用随机或伪随机测试向量时的可测性。例如，一种抗随机故障分析（random resistant fault analysis，RRFA）方法已成功应用于高性能微处理器，以改善逻辑 BIST 中电路的随机可测性。该方法基于对少量随机测试向量进行故障仿真期间收集的统计数据。电路中每个信号的可控性和可观测性测度用统计故障分析（statistical fault analysis，STAFAN）算法中提出的概率模型计算，该算法在 3.4.8 节介绍（STAFAN 是首个仅凭输入测试向量、无需运行故障仿真就能对组合电路故障覆盖率给出相当准确估计的方法）。利用这些数据，RRFA 识别出难以控制和难以观测的信号，以及统计上相关的信号；并根据分析结果推荐应在电路中添加的测试点，以改善电路的随机可测性。

由于跑完所有输入测试向量可能需要很长的仿真时间，这类基于仿真的方法一般用于测试生成或逻辑 BIST 中需要满足极高故障覆盖率目标时的可测性增强指导。这种做法对生命攸关（life-critical）和任务攸关（mission-critical）的应用（如医疗保健以及国防/航空航天行业）至关重要。

#### 2.2.4 RTL 可测性分析方法

前面讨论的可测性分析方法主要用于门级描述的逻辑电路。虽然它们可以用来减轻测试生成负担、指导可测性增强，但在门级进行可测性增强可能代价高昂：会带来面积开销和可能的性能下降；此外还可能需要多轮 DFT 迭代，增加测试开发时间。为解决这些问题，人们提出了许多 RTL 可测性分析方法。

[Lee 1992] 提出的 RTL 可测性分析方法可用于**改善数据通路（data path）的可测性**。==该方法首先构建一个结构图（structure graph）来表示 RTL 电路内的数据传输，其中每个顶点代表一个寄存器，从顶点 $v_{i}$ 指向顶点 $v_{j}$ 的每条有向边代表一个从寄存器 $v_{i}$ 到寄存器 $v_{j}$ 的功能块。结构图中的最大层级称为**时序深度（sequential depth）**，可用于**反映 RTL 电路的测试难度**。这种方法忽略功能块的所有细节。==
 
 [Boubezari 1999] 讨论的 RTL 可测性分析方法可用于改善**基于扫描的逻辑 BIST 电路的随机向量可测性**，其中所有存储元件的输出和输入分别被视为主输入和主输出。为表示信息流和数据依赖关系，需要为每个功能块构造一个**有向无环图**（directed acyclic graph，DAG）。DAG 的每个内部节点对应一个多位的上层运算（如算术、关系、数据传输和逻辑运算），每条边代表一个信号，该信号可由多位构成。这种建模方法保留了功能块有用的上层信息，同时忽略门级实现的细节。随后利用这些信息计算信号线中每个位的 0 可控性、1 可控性和可观测性。

以图 2.4 所示的 n 位行波进位加法器（ripple-carry adder）为例，它由 n 个 1 位全加器组成。通过考察使相应输出为 1 的最小项，$s_{i}$ 和 $c_{i+1}$ 的基于概率的 1 可控性测度（分别记为 $\mathrm{C1}(s_{i})$ 和 $\mathrm{C1}(c_{i+1})$）可按如下方式计算

[Boubezari 1999]：

$$
\mathbf {C} \mathbf {1} (s _ {i}) = \alpha + \mathbf {C} \mathbf {1} (c _ {i}) - 2 \times (\alpha \times \mathbf {C} \mathbf {1} (c _ {i}))
$$

$$
\mathbf {C} \mathbf {1} (c _ {i + 1}) = \alpha \times \mathbf {C} \mathbf {1} (c _ {i}) + \mathbf {C} \mathbf {1} (a _ {i}) \times \mathbf {C} \mathbf {1} (b _ {i})
$$

其中

$$
\alpha = \mathrm{C} 1 (a _ {i}) + \mathrm{C} 1 (b _ {i}) - 2 \times \mathrm{C} 1 (a _ {i}) \times \mathrm{C} 1 (b _ {i})
$$
其中，$\alpha$ 是 $(a_{i}\oplus b_{i})=1$ 的概率，因此 $C1(s_{i})$ 就是 $(a_{i}\oplus b_{i}\oplus c_{i})=1$ 的概率。在 n 位行波进位加法器中，从最左边的全加器向最右边的全加器依次应用上述公式，即可得到每个输出的 1 可控性。该计算可以按输入数量以线性时间完成。n 位行波进位加法器中每个输出 l 的基于概率的 0 可控性记为 $C0(l)$，其值为 $1-C1(l)$。

接下来，考虑 n 位行波进位加法器中输入 l 对输出 $s_{i}$ 的基于概率的可观测性，记为 $\mathrm{O}(l, s_{i})$。$\mathrm{O}(l, s_{i})$ 定义为 l 上的信号变化会引起 $s_{i}$ 上信号变化的概率。根据 1 位加法器的布尔函数，输入 $a_{i}$、$b_{i}$ 或 $c_{i}$ 上的任何变化总能在 $s_{i}$ 处被观测到。因此有：

$$
\mathbf {O} (a _ {i}, s _ {i}) = \mathbf {O} (b _ {i}, s _ {i}) = \mathbf {O} (c _ {i}, s _ {i}) = \mathbf {O} (s _ {i})
$$

![](<assets/VLSI Test Principles and Architectures(MinerU)/image_29.jpg>)

■ FIGURE 2.4 由 n 个全加器组成的行波进位加法器。

其中 $i = 0, 1, \ldots, n - 1$。另一方面，第 i 级的输入 l 对输出 $s_{k}$（即 O(l, $s_{k}$)，其中 k > i）的基于概率的可观测性，取决于进位输出从第 i 级向输出 $s_{k}$ 的传播。该计算留作本章末尾的习题。

总体而言，RTL 可测性分析有时能给出比门级可测性分析更准确的结果，原因是 RTL 模型中再汇聚扇出的数量通常远少于门级模型。RTL 可测性分析也比门级可测性分析更省时，因为 RTL 模型比等效的门级模型简单得多；然而，将 RTL 可测性分析实际应用于复杂 RTL 设计的可测性增强，仍然是一个具有挑战性的研究课题。

## 2.3 可测试性基础设计

如上一节所述，组合逻辑的可测性随组合逻辑级数的增加而下降。更严重的问题是，时序电路难以获得良好的可测性：由于内部状态众多，将时序电路置为所需的内部状态可能需要非常多的输入事件；而且，从主输出辨认时序电路确切的内部状态可能需要很长的检查实验（checking experiment）。因此，作为系统化可测性设计（design for testability，DFT）方法的一部分，需要一种更结构化（structured）的方法来测试包含大量时序逻辑的设计。

早期为改善可测性提出了许多专用（Ad Hoc）技术。这些技术依靠对电路做局部修改，并认为这种修改方式能带来可测性改善。专用 DFT 技术确实能带来一些实际的可测性改善，但其效果是局部的、非系统性的；而且这些技术不成体系，意味着在每个新设计上都得以不同方式重复实施，结果往往难以预料。由于其专用的（ad hoc）性质，所需 DFT 特性的实现耗时也难以预估。

结构化方法的引入，是为了让 DFT 工程师遵循一套系统化的流程来改善设计的可测性。结构化 DFT 技术可以作为设计流程的一部分被轻松纳入并加以预算规划，并能产生预期的效果；此外，结构化 DFT 技术也更容易实现自动化。迄今为止，电子设计自动化（electronic design automation，EDA）供应商已能提供成熟的 DFT 工具来简化并加速 DFT 任务。扫描设计（scan design）是本章的主题，已被证明是最有效的结构化 DFT 方法学之一：它不仅能达到目标故障覆盖率，还能使扫描设计中的 DFT 实现易于管理。在接下来两个小节中，我们先简要介绍几种典型的专用 DFT 技术，然后详细描述结构化 DFT 方法，并特别聚焦于扫描设计。

### 2.3.1 专用（Ad Hoc）方法

专用（Ad Hoc）方法采用一组面向可测性改善的设计实践和修改准则。专用 DFT 技术通常是运用从经验中学到的良好设计实践，或用好的设计实践替换差的设计实践。表 2.5 列出了一些典型的专用技术。本小节介绍**测试点插入（test point insertion）**，这是使用最广泛的专用技术之一；其他几种技术将在 2.6 节进一步描述。更多专用技术可参见 [Abramovici 1994]。

### 2.3.2 结构化 DFT 方法

结构化 DFT 方法试图用一种面向测试的设计方法学来改善电路的整体可测性 [Williams 1983] [McCluskey 1986]。这种方法系统而有章法，结果的可预测性强得多。

扫描设计是最广泛使用的结构化 DFT 方法学，它通过改善时序设计中存储元件的可控性和可观测性来改善电路的可测性。典型做法是将时序设计转换为具有三种工作模式的扫描设计：**正常模式（normal mode）、移位模式（shift mode）和捕获模式（capture mode）**。在这三种模式下进行的电路操作及其相应的时钟周期分别称为正常操作、移位（shift）操作和捕获（capture）操作。

在正常模式下，所有测试信号均被关闭，扫描设计以功能配置运行。在移位模式和捕获模式下，通常使用**测试模式信号 TM 来启用**所有与测试相关的修正，这些修正对于简化测试、调试和诊断任务、提高故障覆盖率以及保证被测电路安全运行是必需的。这些电路模式和操作通过附加的测试信号或测试时钟加以区分，细节将在后续小节描述。

为说明扫描设计的工作原理，考虑图 2.7 所示的时序电路。该电路包含**组合逻辑和三个 D 触发器**。假设组合逻辑中的某个固定型故障（stuck-at fault）f，需要将主输入 $X_{3}$、触发器 $FF_{2}$ 和触发器 $FF_{3}$ 分别置为 0、1、0，才能把故障效应捕获到 $FF_{1}$ 中。由于 $FF_{2}$ 和 $FF_{3}$ 中存储的值无法从主输入直接控制，可能需要施加一长串操作才能把 $FF_{2}$ 和 $FF_{3}$ 置为所需值；此外，要观测触发器 $FF_{1}$ 所捕获值上的故障效应，可能需要很长的检查实验才能把 $FF_{1}$ 的值传播到主输出。由此可见，测试时序电路的主要困难源于电路内部状态难以控制和观测。

扫描设计的概念如图 2.8 所示，它通过为设计中选定的存储元件提供外部访问途径来缓解这一困难。做法是：先将设计中选定的存储元件转换为扫描单元（scan cell），再把它们串联起来构成一个或多个移位寄存器，称为扫描链（scan chain）。在图 2.8 所示的扫描设计中，n 个存储元件在移位模式下被配置成一个移位寄存器，任意测试激励和测试响应都可以分别在 n 个时钟周期内移入和移出这 n 个扫描单元，

而不必求助于施加指数数量的时钟周期来迫使所有存储元件进入期望的内部状态。于是，检测图 2.7 中故障 f 的任务变成简单的四步：(1) 切换到移位模式，将所需的测试激励 1 和 0 分别移入 $FF_{2}$ 和 $FF_{3}$；(2) 在主输入 $X_{3}$ 上驱动 0；(3) 切换到捕获模式并施加一个时钟脉冲，把故障效应捕获到 $FF_{1}$ 中；最后 (4) 切换回移位模式，把存储在 $FF_{1}$、$FF_{2}$、$FF_{3}$ 中的测试响应移出，与期望响应进行比较。

由于扫描设计提供了对内部存储元件的访问途径，测试生成的复杂度得以降低。接下来两节将更详细地介绍几种流行的扫描单元设计以及支持扫描设计的扫描体系结构。

## 2.4 扫描单元设计

如上一节所述，扫描单元一般有两个可供选择的不同输入来源。第一个输入是数据输入（data input），由电路的组合逻辑驱动；第二个输入是扫描输入（scan input），由另一个扫描单元的输出驱动，以构成一个或多个移位寄存器，称为扫描链（scan chain）。将扫描链中第一个扫描单元的扫描输入连接到一个主输入、扫描链中最后一个扫描单元的输出连接到一个主输出，即可从外部访问这些扫描链。

由于扫描单元有两个输入来源，必须提供一种选择机制，使扫描单元能在两种不同模式下工作：正常/捕获模式和移位模式。在正常/捕获模式下，选择数据输入来更新输出；在移位模式下，选择扫描输入来更新输出。这样就能从一个或多个主输入将任意测试向量移入所有扫描单元，同时通过一个或多个主输出移出所有扫描单元的内容。本节介绍三种广泛使用的扫描单元设计：Muxed-D 扫描（muxed-D scan）、时钟扫描（clocked-scan）和电平敏感扫描设计（level-sensitive scan design，LSSD）。

### 2.4.1 Muxed-D 扫描单元

D 存储元件是逻辑设计中使用最广泛的存储元件之一，其基本功能是在施加时钟时把逻辑值从输入传到输出。D 触发器是边沿触发的 D 存储元件，D 锁存器是电平敏感的 D 存储元件。用于替换 D 存储元件的最常用扫描单元是 Muxed-D 扫描单元（muxed-D scan cell）。图 2.9a 展示了一种边沿触发的 Muxed-D 扫描单元设计。该扫描单元由一个 D 触发器和一个多路选择器组成，多路选择器用扫描使能（scan enable，SE）输入在数据输入（DI）和扫描输入（SI）之间进行选择。

### 2.4.3 LSSD扫描单元

Muxed-D 扫描单元和时钟扫描单元一般用于边沿触发的、基于触发器的设计，而 LSSD 扫描单元（LSSD scan cell）用于电平敏感的、基于锁存器的设计。图 2.12a 展示了 [Eichelberger 1977] 中描述的极性保持移位寄存锁存器（polarity-hold shift register latch，SRL）设计，它可以用作 LSSD 扫描单元。该扫描单元包含两个锁存器：主两端口 D 锁存器 $L_{1}$ 和从 D 锁存器 $L_{2}$。时钟 $C$、$A$、$B$ 用于在数据输入 $D$ 和扫描输入 $I$ 之间选择，以驱动 $+L_{1}$ 和 $+L_{2}$。在 LSSD 设计中，$+L_{1}$ 或 $+L_{2}$ 都可用于驱动设计中的组合逻辑。

为保证无竞态（race-free）运行，时钟 A、B、C 以互不重叠（非交叠）的方式施加。在用 $+L_{1}$ 驱动组合逻辑的设计中，主锁存器 $L_{1}$ 用系统时钟 C 从数据输入 D 锁存系统数据，并将该数据输出到 $+L_{1}$。在用 $+L_{2}$ 驱动组合逻辑的设计中，时钟 A 之后使用时钟 B，把系统数据从锁存器 $L_{1}$ 锁存并输出到 $+L_{2}$。在两种情况下，捕获模式都同时使用时钟 C 和时钟 B 将系统数据输出到 $+L_{2}$。最后，在移位模式下，时钟 A 和时钟 B 先用于从扫描输入 I 锁存扫描数据并输出到 $+L_{1}$，再把扫描数据从锁存器 $L_{1}$ 锁存并输出到 $+L_{2}$，后者随后用于驱动下一个扫描单元的扫描输入。示例操作波形如图 2.12b 所示。

使用 LSSD 扫描单元的主要优点是能够把扫描插入基于锁存器的设计中；此外，采用 LSSD 的设计可以保证无竞态，这是 Muxed-D 扫描和时钟扫描设计做不到的。主要缺点则是该技术需要为附加的时钟布线，从而增加布线复杂度。

## 2.5 扫描架构

本节介绍三种流行的扫描架构。这些扫描架构包括：(1) 全扫描设计（full-scan design），将所有存储元件转换为扫描单元，并使用组合 ATPG 进行测试生成；(2) 部分扫描设计（partial-scan design），仅将一部分存储元件转换为扫描单元，通常使用时序 ATPG 进行测试生成；(3) 随机存取扫描设计（random-access scan design），使用随机寻址机制而非串行扫描链，提供对任意扫描单元的直接读访问或写访问。

### 2.5.1 全扫描设计

在全扫描设计（full-scan design）中，所有存储元件都被替换为扫描单元，这些扫描单元在移位操作期间被配置为一个或多个移位寄存器（也称为扫描链）。这样一来，组合逻辑的所有输入（包括由扫描单元驱动的输入）都可以被控制，组合逻辑的所有输出（包括驱动扫描单元的输出）都可以被观察。全扫描设计的主要优点在于，它把困难的时序 ATPG 问题转化为较简单的组合 ATPG 问题。

全扫描设计的一种变体称为几乎全扫描设计（almost full-scan design），其中一小部分存储元件（有时只有少数几个）不被替换为扫描单元。这些存储元件通常出于性能原因（例如位于关键路径上的存储元件）或功能原因（例如由很小的时钟域驱动、被认为不值得为此付出额外扫描插入开销的存储元件）而未被纳入扫描设计。在这种情况下，这些存储元件可能导致故障覆盖率损失。

如 2.4.3 节所述，若时钟 C 与 B、以及 A 与 B 均不重叠，极性保持 SRL 的操作是无竞争的。这一特性被用来实现 LSSD 电路，保证其在正常模式和测试模式下都无竞争操作。所需的设计规则 [Eichelberger 1977] [Eichelberger 1978] 简要总结如下：

■ 所有存储元件都必须是极性保持锁存器。
\- 锁存器由两个或更多不重叠的时钟控制，使得任何两个存在馈送关系的锁存器不能使用同一个时钟。
\- 必须存在一组时钟外部输入（clock primary inputs），所有 SRL 的时钟端口都由它们控制，控制途径可以是单一时钟树，也可以是经过 SRL 和/或非时钟外部输入门控的逻辑。此外，还应满足以下三个条件：(1) 当时钟外部输入无效时，所有 SRL 的时钟输入必须无效；(2) 任何 SRL 的时钟输入必须能由一个或多个时钟外部输入控制；(3) 任何时钟不得与另一个时钟或其补码做与运算。
\- 时钟外部输入不得直接或通过组合逻辑馈送 SRL 的数据输入。
■ 每个系统锁存器都必须是某个 SRL 的一部分，且每个 SRL 都必须是某条扫描链的一部分。
■ 在以下条件下存在扫描状态：(1) 在扫描操作期间，每个 SRL 或扫描输出 SO 仅是其扫描链中前一个 SRL 或扫描输入 SI 的函数；(2) 除移位时钟外的所有时钟在 SRL 时钟输入处均被禁用。

### 2.5.2 部分扫描设计

与电路中所有存储元件都被替换为扫描单元的全扫描设计不同，部分扫描设计（partial-scan design）只要求将一部分存储元件替换为扫描单元并连接成扫描链 [Trischler 1980] [Abadir 1985] [Agrawal 1987] [Ma 1988] [Cheng 1989] [Saund 1997]。部分扫描设计在工业界的应用远早于全扫描设计成为主流扫描架构。它同样可以用 muxed-D 扫描单元、时钟式扫描单元或 LSSD 扫描单元实现。根据部分扫描设计的结构，应使用组合 ATPG 或时序 ATPG，两者都在第 4 章中介绍。
